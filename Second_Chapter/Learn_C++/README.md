1. 怎样通过指针来遍历数组

```c++
#include <iostream>
using namespace std;
 
int main() {
    int arr[] = {1, 2, 3, 4, 5};
    int* ptr = arr;
    printf("指针当前指向的元素: %d\n", *ptr);
    ptr++;
    printf("递增指针后指向的元素: %d\n", *++ptr); //不得不品味的一环，
    return 0;
}
```
*++ptr = arr[1]
++*ptr = arr[0] + 1
*ptr++ = 输出arr[0] ， 而后指向arr[1]
(*ptr)++ = 输出arr[0]，而后变成arr[0]+1
c++的指针还是太曼妙了

2. 函数内部一般无法进行修改传入的参数，如果要修改需要通过什么样的方式，原理是什么？

原理就是把指针作为一个可传入的参数进行，或者值引用吧。

如：
```cpp
void g(int* p) { *p = 99; }
void h(int& r) { r = 99; }

int a = 1;
g(&a); // a = 99
h(a);  // a = 99
```

1. 了解类是什么，对象是什么？
类用于指定对象的形式，是一种用户自定义的数据类型，它是一种封装了数据和函数的组合。
