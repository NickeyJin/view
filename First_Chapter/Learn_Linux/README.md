4. 下面提到的几个常见命令的用法
pwd 获取当前工作区的完整路径
ls 知道工作区里有什么

cp copy辅助
mv move移动
rm remove删除
mkdir 创建文件夹

chmod 设置每个文件(夹)的访问权限
sudo 临时借用一下别人的权限来访问和修改文件 **不等于** su 切换用户
